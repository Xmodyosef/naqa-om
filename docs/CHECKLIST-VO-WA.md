# قائمة تجربة VoiceOver + واتساب | VoiceOver & WhatsApp checklist

**الموقع:** https://xmodyosef.github.io/naqa-om/?v=20261123t  
**مدتها:** ٥–١٠ دقائق · **مجاني · على آيفونك**

---

## أ) VoiceOver (iPhone)

1. الإعدادات → تسهيلات الاستخدام → VoiceOver → تشغيل  
   **أو** ثلاث نقرات على الجانب/المنزل (إن مفعّل الاختصار)
2. افتحي Safari → الرابط أعلاه
3. مرّري يمين/يسار بين العناصر — اسمعي:
   - [ ] تخطي إلى المحتوى (Skip link) يظهر بأول Tab/Swipe
   - [ ] شعار نقاء / Naqa
   - [ ] حقل البحث له اسم «بحث…»
   - [ ] زر اللغة / السلة / المفضلة بأسماء واضحة
   - [ ] بطاقة منتج: اسم + سعر (مو بس صورة صامتة)
4. افتحي منتج:
   - [ ] عنوان التفاصيل يُقرأ
   - [ ] أزرار + / − للكمية لها أسماء
   - [ ] إضافة للسلة → تسمعين إعلان «تمت الإضافة…»
5. افتحي السلة ثم اضغطي **Escape** (لوحة خارجية) أو زر إغلاق — [ ] يرجع التركيز
6. بدّلي EN/AR — [ ] تسمعين إعلان اللغة
7. أطفئي VoiceOver بعد الانتهاء

### إنجليزي مختصر
Turn on VoiceOver → open store → swipe through header, product card, product sheet, cart; confirm labels and “added to cart” announcement; toggle language.

---

## ب) طلب واتساب حقيقي

1. أضيفي منتجين للسلة  
2. إتمام الطلب: اسم + هاتف + ولاية  
3. أرسلي — يفتح واتساب برسالة فيها:
   - [ ] رقم الطلب  
   - [ ] المنتجات + SKU  
   - [ ] المجموع ر.ع  
   - [ ] **بدون** رابط base64 طويل  
4. راجعي الرسالة على جهازك قبل ما تطلعين للزبائن

## ج) PWA (اختياري دقيقة)

- Safari → مشاركة → **إضافة إلى الشاشة الرئيسية**  
- [ ] تفتح بأيقونة نقاء بدون شريط متصفح كامل

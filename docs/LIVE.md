## 1) ورك فلو الزبونة (المتجر)

```
دخول index.html
  → هيدر: شعار · ثيم · لغة · مفضلة · سلة
  → بحث (حي أثناء الكتابة) + زر بحث
  → تصنيفات: الكل / عناية / وجه / شفاه / عيون / حواجب / أدوات / شعر
  → الرئيسية (home):
       · بنر واحد قابل للسحب (hero-swipe) 3–5 حملات
       · قضبان منتجات الحملات (بدون زحف تلقائي)
       · عروض / اهتمامات / ماركات
  → اختيار تصنيف أو بحث أو كتالوج:
       · شبكة منتجات #grid
       · بدون نقاط/صور مصغّرة تحت الصور
  → فتح منتج (ورقة sheet):
       · الصورة أولاً · سحب يمين/يسار بين الصور فقط
       · سحب لتحت = إغلاق الورقة (لا إعادة تحميل)
       · أضف للسلة · كمية · مفضلة
  → السلة → واتساب / دفع (تحويل بنكي مخفي حتى يُضبط الاسم والآيبان)
```

### ملفات المتجر الحية
| دور | ملف |
|-----|-----|
| هيكل | `index.html` |
| JS للزبونة | `js/store.min.js` (يُبنى من مصادر `scripts/build-store.sh`) |
| CSS للزبونة | `css/store.min.css` (من `css/store/*`) |
| كتالوج | `data/products.min.js` + `data/products.detail.json` |
| أوفررايد حي | Firestore `naqa/overrides` + `data/overrides.json` |

### بناء المتجر
```bash
bash scripts/build-store.sh
# ثم ارفع v= في index.html (store.min.js + store.min.css)
git add js/store.min.js css/store.min.css index.html <sources>
git commit && git push origin main
```

## 2) ورك فلو اللوحة (admin)

```
admin.html → Firebase Auth (إيميل/Google)
  → loadAdminModules (بعد الدخول فقط)
  → أقسام: رئيسية · طلبات · منتجات · تقييمات · عملاء · مالية · إعدادات
  → منتجات: إضافة/تعديل/إخفاء عبر overrides → Firestore
  → طلبات: حالات + إلغاء بتأكيد (بدون حذف قاسٍ)
```

- كتالوج اللوحة: `data/products.admin.min.js?v=…` (يمكن رفع مفتاحه وحده لتظهر المنتجات الجديدة).
- باقي موديولات اللوحة قد تبقى على مفتاح أقدم حتى يُطلب تحديثها.
- **لا سايدبار.** حبوب تنقل فقط. بحث الطلبات صغير (≤220px).

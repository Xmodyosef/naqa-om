# قواعد ممنوع اللمس — لوحة نقاء

آخر تحديث: 2026-11-25  
الغرض: ما نعيدش نلمس شيء **سليم** إلا بطلب صريح من صاحبة المتجر.

## سليم · لا تُلمس إلا بطلب صريح

| المنطقة | ملاحظة |
|---------|--------|
| شاشة الدخول (Firebase) | شكل + Google + إيميل/كلمة سر |
| إخفاء المنتج | مثبت بعد تجربة صاحبة المتجر |
| الأسعار | التعديل من اللوحة شغال — لا تغيّر المنطق إلا بطلب |
| الكميات / المخزون | الافتراضي **3** لكل المنتجات؛ التعديل اليدوي من اللوحة يبقى |
| تأكيد إلغاء الطلب | لا حذف طلب |
| تصدير Excel طلبات/مالية | لا تكسر الأزرار |
| فلتر التاريخ | لا تكسر |
| 50 منتج / صفحة | لا تغيّر الحجم إلا بطلب |
| السايدبار (رئيسي + فروع) | لا تجارب تنقل جديدة إلا بطلب |
| إزالة رمز GitHub من الإعدادات | لا ترجع حقل التوكن |
| لا PIN في الواجهة | Firebase يكفي |
| لا تسجيل زبائن في المتجر الآن | مؤجّل |
| بحث المنتجات في اللوحة | ملغى — البحث للطلبات فقط |
| نشر التقييمات عبر Firestore | انشري للمتجر من تبويب التقييمات |
| تعديل منتج + كيبورد (بدون position:fixed) | لا ترجع scroll-lock الثابت على شاشة التعديل |
| بيانات البنك | مؤجّلة لين الربط |

## كيف نشتغل

1. قبل أي تعديل: اقرأ هذه القائمة.
2. بعد كل خطوة: صاحبة المتجر ترد **سليم** / **شغال + تعديلات** / **مو شغال**.
3. **سليم** = يُقفل في هذه القائمة فوراً.
4. ممنوع «تحسين صامت» لمنطقة سليم.
5. ممنوع إعادة فتح: PIN · توكن GitHub · حذف طلب · شاشة الدخول.

## مسموح لمسه (قائمة عمل حالية)

- تفعيل/اختبار Firestore للمزامنة السحابية (سعر/كمية) إن لزم
- مسار الطلبات السحابي (٦.٧) عند الطلب
- ضغط صور الكتالوج عند الطلب
- استيراد Excel / رفع صور عند الطلب
- أعطال جديدة تبلغها صاحبة المتجر

## كمية افتراضية

- كل منتج في الكتالوج: `stock: 3` ما لم تُغيّر من اللوحة (overrides).
- الحقل الفاضي في اللوحة يُعرض **3** لا شرطة فارغة.

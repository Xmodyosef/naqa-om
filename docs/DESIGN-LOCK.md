## 1) الألوان — لا تستبدليها

هذه القيم مصدرها `css/store/base.css` و `css/admin/base.css`. لا تضيفين لوحة ألوان ثانية.

| الاسم | القيمة | الاستعمال |
|---|---|---|
| الخلفية | `#fdf8f6` | خلفية المتجر واللوحة (نهاري) |
| البطاقة | `#ffffff` | الكروت والحقول |
| النص | `#1f1a17` | العناوين والنص الأساسي |
| النص الخافت | `#6b625c` | ملاحظات، وصف |
| الخط الفاصل | `#efe4df` | حدود الكروت والأزرار الشبح |
| الوردي الفاتح | `#c46b7c` | لمسة فقط في المتجر (`--rose`) |
| الوردي الغامق | `#8d3048` | **الزر الأساسي** في المتجر واللوحة |

الوضع الليلي للمتجر: `html[data-theme="night"]` الموجود في `css/store/base.css`. لا تنسخين ألوان الليل فوق النهار.

الوضع الليلي للوحة: `html[data-admin-theme="dark"]` في `css/admin/theme-mode.css`.

- خلفية الليل `#1a1412`
- البطاقة `#241d1a`
- النص `#f5eeea`
- الخافت `#a89b94`
- الفاصل `#3a2f2a`
- الزر النشط يبقى `#8d3048` بنص أبيض

ممنوع: تركواز، أزرق أساسي، أخضر كعلامة تجارية، أو تدرّج جديد. الأخضر/الأصفر/الأزرق الفاتح مسموح فقط كشارة حالة طلب (جديد / تجهيز / توصيل / تم / ملغي) كما هي في `css/admin/base.css`.

الخط: المتجر `Noto Kufi Arabic`. اللوحة `Noto Sans Arabic` + `IBM Plex Sans`. الاتجاه عربي `rtl`، والإنجليزي يقلب الاتجاه بدون تغيير أماكن الأزرار يدوياً.

## 2) أزرار المتجر — أماكنها ثابتة

### شريط سفلي (dock) — 2026-11-27
ثابت أسفل الشاشة: **الرئيسية · الأقسام · الماركات · السلة · واتساب**.  
ألوان نقاء (`#8d3048` للنشط). يُخفى عند ورقة المنتج/السلة/النوافذ. زر واتساب العائم يُلغى لصالح تبويب الشريط.


الملف: `index.html`. لا تنقلين زراً من الهيدر إلى الفوتر أو العكس.

1. شريط التوصيل المتحرك فوق كل شيء (`#shipBar`).
2. الهيدر من اليمين: الشعار «نقاء»، ثم الثيم (`#themeBtn`)، اللغة (`#langBtn`)، المفضلة (`#wishBtn`)، السلة (`#cartBtn`).
3. تحتهم مباشرة: البحث (`#search`) وزر «بحث» (`#searchGo`) داخل نفس الحبة.
4. تحت البحث: تصنيفات المنتجات (`#cats`) حبوب أفقية. النشطة خلفية `#8d3048`.
5. البطل: «تسوّقي الآن» زر أساسي، ثم «اختبار البشرة» و«واتساب نقاء» أزرار شبح بجانبه وليس تحته في الشاشات العريضة إن كان الصف يتسع.

شكل الزر:

- أساسي `.btn-primary` / `.search-go` / التصنيف النشط: خلفية `#8d3048`، نص أبيض، حبة `border-radius: 999px`.
- شبح `.btn-ghost`: خلفية بيضاء، حد `#efe4df`، نص `#1f1a17`.
- أيقونة الهيدر `.icon-btn`: مربع 44×44، زوايا 12، خلفية بيضاء. لما يكون نشطاً يصير `#8d3048`.

بعد تعديل مصادر التنسيق (`css/store/*.css`) شغّلي `bash scripts/build-store.sh` حتى يتحدث `css/store.min.css`. لا تعدّلين `store.min.css` باليد.

## 3) أزرار اللوحة — أماكنها ثابتة

الملف: `admin.html` + `css/admin/nav.css`. **لا سايدبار.** الآباء صف حبوب فوق، والأبناء صف حبوب تحته.

ترتيب الآباء (من اليمين): الرئيسية، الطلبات، المنتجات، التقييمات، العملاء، المالية، الإعدادات.

- شارة الطلبات = عدد «جديد» فقط.
- أبناء الطلبات: الكل، جديد، جاري التجهيز، جاري التوصيل، تم التوصيل، ملغي — كل واحد معه عدّاد.
- أبناء المنتجات: الكل، ظاهر، مخفي، مخزون منخفض — كل واحد معه عدّاد.

شريط الأدوات (`#topBar`) يظهر حسب القسم فقط:

- الطلبات: بحث صغير (ارتفاع 34px، عرض لا يتجاوز 220px). ممنوع تمديده بعرض الصفحة.
- المنتجات: زر «إضافة منتج» + قائمة Excel (تصدير / استيراد). الزر يبدأ `hidden` حتى لا يومض عند التحديث.
- باقي الأقسام: لا بحث ولا زر إضافة.

إعدادات اللوحة بطاقات فقط: المتجر، الحساب (إيميل + خروج)، الخصوصية، النشاط. **ممنوع** إرجاع حقل رمز GitHub أو PIN أو أزرار «حفظ على جهازي / نشر للكل».

الدخول: إيميل + كلمة سر Firebase، و«نسيت كلمة المرور»، و«المتابعة مع Google». لا شاشة PIN.

## 4) الجوال والكمبيوتر

- تحت عرض 1100px: شكل الجوال الحالي هو المعتمد. لا تعيدون تصميمه.
- من 1100px وفوق فقط: `css/admin/desktop.css` (عمودان للمنتجات والطلبات، أرقام المالية في صف، الإعدادات بطاقتان). أي تحسين كمبيوتر يُكتب هناك، لا داخل قواعد الجوال.
- صفحة الدخول على الكمبيوتر تبقى بطاقة في الوسط، لا تمتد بعرض الشاشة.

## 5) قبل ما تعدّلين

1. اقرئي هذا الملف و `docs/ENGINEERING-RULES.md`.
2. إذا الطلب «تحسين شكل» بدون تحديد زر أو لون: لا تنقلين شيئاً. اسألي.
3. أي نص جديد: عربي في `dict-ar.js` وإنجليزي في `dict-en.js` معاً.
4. بعد التعديل: اذكرِي في الرسالة أي قاعدة من هذا الملف لمستِها، ولماذا.

## 6) قفل واجهة المتجر — 2026-11-27 (لا تُلغى بدون طلب)

1. **البنر:** بنر واحد `.hero-swipe` قابل للسحب. ممنوع رجوع البنرات المكدّسة أو زحف القضبان التلقائي.
2. **التصنيفات في `#cats`:** الكل، عناية، وجه، شفاه، عيون، حواجب، أدوات، شعر فقط. **ممنوع** زر «عطور».
3. **تحت صور المنتج / البنر:** ممنوع نقاط carousel-dots وممنوع شريط thumbs. السحب فقط؛ كل صور المنتج تبقى في المسار.
4. **ورقة المنتج:** الصورة أولاً. سحب لتحت = `closeSheet` فقط (ممنوع `location.reload`).
5. **سحب الصور يمين/يسار:** داخل `.carousel-track` فقط. الورقة `overflow-x: hidden` و`overscroll-behavior-x: none/contain` — ممنوع انزلاق لفراغ بجانب الصورة.
6. **أثناء التمرير:** إخفاء البحث والتصنيفات يكون بطيّ الارتفاع (`max-height:0`) لا بمساحة فارغة محجوزة.
7. **البحث:** حبة كاملة تحت الشعار؛ زر «بحث» داخلها؛ نتائج حية؛ لا تكسير تخطيط الهيدر.
8. **زر العروض في البطل:** يذهب للعروض/الكتالوج — النص المناسب «تسوّقي العروض» إن وُجد.
9. بعد أي CSS متجر: `bash scripts/build-store.sh` + رفع `?v=` في `index.html`.

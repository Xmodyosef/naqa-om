# لوحة تحكم نقاء — هيكل الملفات

لوحة تحكم مبسّطة لمتجر GitHub Pages ثابت.

## التبويبات
| تبويب | وظيفة |
|--------|--------|
| الرئيسية | ملخص مبيعات / طلبات / مخزون منخفض |
| الطلبات | حالات + فلتر + واتساب |
| المنتجات | قائمة + تعديل كامل |
| العملاء | من بيانات الطلبات |
| المالية | إجماليات ومتوسط طلب |
| الإعدادات | PIN / GitHub token / خروج |

## الملفات
```
admin.html              # الهيكل فقط
css/admin.css           # أنماط اللوحة
js/admin/core.js        # حالة مشتركة + تخزين + GitHub put
js/admin/products.js    # قائمة وتحرير المنتجات
js/admin/orders.js      # الطلبات والحالات
js/admin/customers.js   # العملاء
js/admin/finance.js     # مالية وتحليلات
js/admin/dashboard.js   # الصفحة الرئيسية
js/admin/settings.js    # إعدادات وحفظ ونشر
js/admin/app.js         # تشغيل + تبويبات + أحداث
```

إصلاح قسم معيّن = عدّل ملفه فقط ثم ارفع.
